# V2 质量报告 · V2 Quality Report

本页记录 2026 年 11 月 10 日 V2 批次留存的抽样结果与拦截统计。现行验收门槛、外部参考和代码限制见 [质量要求](质量要求.md)。

## 统计口径

- **锚定率**为 DTW 产生定位的参考歌词行数占比。DTW 可能给弱匹配分配时间，锚定结果需结合召回和同步指标阅读。
- **歌词覆盖**为输出 LRC 行数与参考歌词行数之比。**文字召回**为 LRC 的去重汉字集合在该段转写中出现的比例。
- **同步行占比**为能够在转写的时间窗口内匹配的合格歌词行比例。当前检查用每行前六个拼音音节，要求至少 60% 按序匹配。代码搜索范围和旧日志里的「±2 s」文字存在差异，表中保留抽样脚本计算的比例。
- **中位误差和 P95**基于命中行的 LRC 起点与匹配转写音节起点之差。抽查脚本重新计算指标，使用的仍是排轴参考的 ASR 时间戳。中位误差显示 0.00 s 表示与该参考在表格精度内一致，真实同步精度需人工标注验证。

## English summary

This report preserves the five-track spot check and the rejection counts from the first 38 sessions of the November 10, 2026 V2 batch. Track columns show anchor coverage, distinct-character recall, matched-line share, median timing error, first and last lyric start, and cut duration. Timing error is measured against the automatic transcription timestamps used by the alignment process. Evaluating real timing accuracy requires independently annotated audio.

The rejection table counts records rather than sessions. The repository contains sanitized examples. Reproducing the aggregate requires the batch data. See [Quality Requirements](质量要求.md#english) for measurement references and implemented thresholds.
