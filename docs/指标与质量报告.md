# 质量指标说明与实测样本

## 1. 指标定义

| 指标 | 定义 | 门槛 |
|---|---|---|
| 锚定率 anchor | 官方歌词行中，DTW 在演唱里找到确定位置的比例 | ≥85% |
| 歌词覆盖 cover | 输出的 LRC 行数 / 官方歌词行数 | ≥80% |
| 文字召回 recall | LRC 用字的字符集，有多大比例真的出现在该段转写里 | ≥66% |
| 行同步率 sync | LRC 行起始时间 ±2s 内能找到对应演唱音节的行占比 | ≥80% |
| 中位误差 med | 命中行的 \|LRC 时间 − 转写音节时间\| 中位数 | ≤0.30s |
| 95 分位 p95 | 同上 95 分位 | ≤0.90s |
| 说话占比 talk | 片段内被判"说话"的时长占比 | ≤8% |
| 响度 LUFS | EBU R128 整段响度（只测量） | −24~−6 告警 |
| 真峰值 TP | 最大真峰值 dBTP | ≤−1 告警 |

## 4. 已知的指标局限

- **同步率与中位误差是自洽指标**：参照物是同一份 whisper 时间戳，不是人工标注的真值。
  若要独立真值，需要用音素级强制对齐（如 wav2vec2/MMS）抽样复算，或人工打点。
- 因此本项目把这两项当作"筛掉明显错位"的闸门，而不是精度宣称。
