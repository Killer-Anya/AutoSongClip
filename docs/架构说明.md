# 架构与数据流 / Architecture and Data Flow

## 入口

| 模式 | 入口与输入 | 使用的服务 |
| --- | --- | --- |
| 单场 | `pipeline/pipe_v3.py <录播网址或 BV> <标题> [日期] [分 P]`。链接中的 `p` 指定分 P，显式参数优先。 | B 站音轨、网易云参考歌词、GLM 或兼容文本服务。MiMo 音频复核可用 `MIMO_VERIFY=0` 关闭。 |
| 队列 | `pipeline/run_v3.py [场次数]`。从 `queue/streams_v3.json` 读取场次、分 P、重试次数与状态。 | 与单场处理相同。每次启动任务前检查文本服务，失败时保留任务，待服务恢复后重新运行。 |
| 缓存重处理 | `pipeline/pipe_offline.py <BV> [分 P]`。复用已有音轨、转写及歌词语料。 | 关闭模型调用。候选或歌词不足时可以访问网易云。 |

同一录播的分 P 分别处理。第一 P 的场次标记为 BV 号，后续使用 `BV号_pN`。

## 文件和阶段

1. **源音轨与转写。** `bili.py` 选择可用的高带宽音轨，原始 M4A 写入 `res/`。`decode_wav.py` 生成 16 kHz 单声道分析音频。faster-whisper small 把词级时间写入 `queue/asr_v3/<场次>.jsonl`。默认每块 300 秒，整场 beam 2。仅当曲目切片内转写句数不足时，才单独用 beam 5 重转。
2. **候选、识曲、切点。** `qwen_sent.py` 使用配置的文本模型给转写分类，`seg_regions.py` 合并演唱区间。`identify2.py` 结合歌词检索、转写和词级对齐筛选曲名。切点由音频和演唱标签决定。`boundary.py` 用 20 ms RMS 窗、10 ms 步长估计噪声底并搜索静音。
3. **歌词时间轴。** `align_lib.py` 和 `dtw_align.py` 使用拼音和本地词级时间，填补缺失锚点并修正重复段。`gates.py` 和 `qc.py` 负责歌词与时间轴检查。音频模型可抽查片段，复核状态单独写入 `audio_review`。
4. **交付与审核。** `library/` 存放 M4A、LRC 和 ASS。待发布索引为 `queue/songs_index_new.json`，拒绝原因与指标分别记录在 `qc_rejects.json`、`qc_metrics.jsonl`。审核并核对播放器媒体路径后，`tools/publish_new.py` 合并正式索引并构建页面。
5. **网页。** `lib/build_site.py` 把正式索引嵌入 `site/web/index.html`。播放器读取 `site/audio/`。生成页面可能含完整歌词和场次信息，提交源码前应保留空曲库模板。

## 文本服务与资源配置

默认文本接口为 `http://127.0.0.1:18090/v1/chat/completions`，健康检查为同一代理的 `/v1/models`。使用自己的兼容服务时，在启动命令的终端按服务商提供的地址和模型名称设置以下环境变量。将示例域名替换为实际服务域名。

```bash
export JUDGE_API='https://your-provider.example/v1/chat/completions'
export JUDGE_HEALTH='https://your-provider.example/v1/models'
export JUDGE_MODEL='your-model-name'
read -rs -p 'API key: ' JUDGE_KEY
export JUDGE_KEY
```

配置优先级为 `JUDGE_*` 环境变量、项目本地的 `run/judge.env`、默认设置。MiMo 使用本机 18090 端口的代理和 `TONGJI_API_KEY`。运行纯文本复核时可设 `MIMO_VERIFY=0 MIMO_ASR=0 MIMO_ANCHOR=0`。

`SONG_CUT_HOME` 指定工作根目录。FFmpeg 和 FFprobe 依次查找 `SONG_CUT_FFMPEG` / `SONG_CUT_FFPROBE`、`bin2/` 和系统 PATH。Whisper 默认从 `models/small` 加载，可用 `SONG_CUT_MODELS` 设置上一级目录。服务器采用串行队列和内存守卫。

验收口径见 [质量要求](质量要求.md)。实测结果与变更依据见 [指标与质量报告](指标与质量报告.md) 和 [开发日志](开发日志.md)。
