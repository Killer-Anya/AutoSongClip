# V1 技术方案 / V1 Architecture

[简体中文](#简体中文) · [English](#english)

## 简体中文

V1 是[线上歌回曲库](http://101.43.7.149:18081/web/)采用的处理方案。目标是从长录播中保留连贯的演唱，去掉曲目之间的说话和空白，并给每次演唱提供可跟随的歌词。

1. **下载和转写。** 拉取 B 站录播的 AAC 音轨。faster-whisper small 在 CPU 上以 INT8 运行，每 300 秒分块，beam size 为 5，不预先用 VAD 去除音频。GLM-5.3-Flash 根据转写逐句区分演唱和说话。
2. **合并、识曲和切片。** 合并间隔不超过 22 秒的演唱句，遇到明确说话就断开，保留至少 60 秒的候选。用候选唱词从网易云音乐检索歌名与参考歌词，再用 GLM 复核。FFmpeg 从首句演唱的起点切到末句演唱的终点，流复制一个连续区间，不加首尾留量。
3. **同步歌词。** 取切片内的本地转写，减去切片起点，再对参考歌词的拼音做动态时间规整（DTW）。保留实际唱到的行，补齐弱锚点并局部重锚，生成严格递增的逐行时间轴。V1 有歌词锚定率、覆盖率和行数等自动检查，详细验收范围见[质量要求](质量要求.md)。
4. **听审和发布。** 抽听并核对切点、曲名和歌词同步，再将审核过的音频及索引交给网页播放器。V1 未使用 MiMo。

**已知取舍。** 首尾直接按有声唱句截取，所以有些片段会少一段前奏或尾音。复查时应对照原录播听切点两侧，分清应保留的伴奏与曲间杂音。[听审要点](质量要求.md)

**公开范围。** 本页根据维护者对原始脚本的核对整理。线上 V1 的批处理入口是 `run_queue.py`，单场入口是 `pipe_v2.py`；脚本名里的 `v2` 是内部编号。V1 原始批处理脚本未随当前公开版发布。[V2 批处理与复现说明](V2-复现说明.md)中的命令运行的是后来试用的 V2。[试运行与回退复盘](项目复盘.md)

## English

V1 is the workflow used for the [live song library](http://101.43.7.149:18081/web/). It extracts continuous performances from long recordings, removes speech and gaps between songs, and supplies lyrics that follow each performance.

1. **Download and transcribe.** Fetch the Bilibili AAC audio. Run faster-whisper small on the CPU in INT8 mode, in 300-second blocks, with beam size 5 and no voice activity filter. GLM-5.3-Flash labels transcript sentences as singing or speech.
2. **Group, identify, and cut.** Group sung lines separated by up to 22 seconds, split at speech, and retain candidates at least 60 seconds long. Search NetEase Cloud Music for the song and reference lyrics, then cross-check the candidate with GLM. FFmpeg stream-copies a single span from the start of the first sung line to the end of the last, with no added padding.
3. **Align the lyrics.** Use transcript timestamps inside the cut, shifted relative to its start. Align the pinyin reference with dynamic time warping (DTW), keep the sung lines, and refine weak anchors to obtain strictly increasing line timestamps. V1 checks lyric anchors, coverage, and line count. See the [quality notes](质量要求.md#english).
4. **Listen and publish.** Spot-check cut boundaries, titles, and lyric timing, then publish approved audio and its catalog to the web player. V1 used no MiMo.

**Known tradeoff.** Since cuts use the outermost sung lines, some clips omit part of the instrumental intro or the final decay. Listen on either side of the cut in the original recording to distinguish accompaniment worth preserving from between-song noise. [Listening checklist](质量要求.md#english)

**Public release scope.** This page is based on the maintainer's review of the original scripts. The deployed V1 used `run_queue.py` and the single-recording entry point `pipe_v2.py`, whose filename used an internal revision number. Those original V1 scripts are not part of the current public package. The [V2 batch instructions](V2-复现说明.md#english) run the later V2 trial. [Trial and rollback retrospective](项目复盘.md#english)
