# V1 技术方案 / V1 Architecture

[简体中文](#简体中文) · [English](#english)

## 简体中文

V1 是[线上歌回曲库](http://101.43.7.149:18081/web/)采用的处理方案。目标是从长录播中保留连贯的演唱，去掉曲目之间的说话和空白，并给每次演唱提供可跟随的歌词。

1. **定位演唱。** 从 B 站获取录播的 AAC 音轨。本地 Whisper 生成带时间戳的转写，GLM 依据文本辅助区分唱歌与说话，得到候选演唱区间。
2. **识曲和截取。** 用候选唱词查询网易云音乐并核对歌名与参考歌词。用 FFmpeg 从源音轨流复制一段连续的演唱，保留原码流。
3. **同步歌词。** 将参考歌词和本地转写对齐，生成相对切片起点的逐行歌词时间。遇到重复副歌或同名歌曲时需核对具体演唱。
4. **听审和发布。** 人工抽听确认切点、曲名和歌词同步，审核后的音频与索引交给网页播放器。V1 没有使用 MiMo 作为验收条件。

**已知取舍。** 少数片段的前奏或尾音会略短。自动转写善于定位有声唱词，不能仅凭首末歌词时间判断纯伴奏或尾音应该在哪里截止。复查时，应回到原录播，抽听切点两侧，判断哪些内容应保留。[听审要点](质量要求.md)

**公开范围。** 本页记录部署过的 V1 方案。公开版提供本地播放器及单独留存的 [V2 批处理源码和复现说明](V2-复现说明.md)，其中的命令运行的是 V2。[试运行与回退复盘](项目复盘.md)

## English

V1 is the workflow used for the [live song library](http://101.43.7.149:18081/web/). It extracts continuous performances from long recordings, removes speech and gaps between songs, and supplies lyrics that follow each performance.

1. **Locate the singing.** Fetch the AAC audio from the Bilibili recording. Local Whisper produces a timestamped transcript. GLM classifies the text to help identify candidate singing intervals.
2. **Identify and cut each song.** Search NetEase Cloud Music using the candidate lyrics and check the song title and reference lyrics. FFmpeg uses stream copy to extract one continuous performance while preserving the source encoding.
3. **Align the lyrics.** Match reference lyrics to the local transcript and express the line start times relative to the clip. Repeated choruses and songs with the same title call for checking the specific performance.
4. **Listen and publish.** Review the cut boundaries, title, and lyric timing by ear. Publish approved audio and its catalog to the web player. V1 did not require MiMo for acceptance.

**Known tradeoff.** A few clips have slightly shortened intros or endings. Transcription can locate sung words, while lyric timestamps alone cannot define where instrumental sections or the final decay should end. Review both sides of the cut against the source recording. [Listening checklist](质量要求.md#english)
